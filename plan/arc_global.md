# Arc global — Yaku-apa

> Structure provisoire basée uniquement sur les éléments déjà établis.

## Phase 1 — Arrivées et convergences

Fonction :
- présenter les protagonistes séparément ;
- montrer leurs arrivées décalées au Japon ;
- installer la vie d'étudiants étrangers ;
- faire converger leurs trajectoires vers le même logement.

Éléments :
- introductions séparées ;
- flashbacks possibles ;
- école de langue ;
- difficultés quotidiennes ;
- début de la cohabitation.

## Phase 2 — Share house

Fonction :
- former le groupe ;
- installer les relations ;
- créer le problème de loyer ;
- révéler le lien avec le milieu yakuza.

Point de rupture :
la confrontation avec le premier clan.

## Phase 3 — Incident fondateur

Fonction :
- faire basculer le récit ;
- confronter les protagonistes à une violence qu'ils ne cherchaient pas ;
- provoquer la disparition accidentelle du premier clan.

Résultat :
le groupe ne peut plus revenir simplement à sa vie d'avant.

## Phase 4 — Survivre aux conséquences

Fonction :
- révéler les autres factions ;
- faire comprendre aux héros comment leur acte est interprété ;
- transformer une rumeur / réputation en menace concrète.

Décision majeure :
créer leur propre organisation.

## Phase 5 — Organisation improvisée

Fonction :
- apprendre à tenir un territoire ;
- créer une structure ;
- gérer le décalage entre l'image terrifiante du groupe et la réalité de quatre étudiants étrangers ;
- maintenir school-life et baito.
